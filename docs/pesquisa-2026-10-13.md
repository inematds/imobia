# Pesquisa inicial — imobia (2026-10-13)

Contexto: imobiliária real (venda + locação, 5 corretores). WhatsApp via Evolution, IA atende 24h,
equipe usa Telegram + painel de monitoramento. Sistema próprio, sem formulários.

## O que aproveitar dos nossos projetos (só como referência)
- **imob360** (`~/projetos/imob360`, não compila): modelo de dados em
  `packages/database/prisma/schema.prisma` — Property (:310), Person com `types[]` e
  `searchPreferences` (:415), Lead com funil fixo (:488), Visit com lembretes (:539),
  Contract (:585), WhatsAppMessage (:961). Webhook Evolution `messages.upsert` com
  auto-criação de lead e dedup por telefone (`apps/api/.../whatsapp.routes.ts:454`).
- **wacrm** (`~/projetos/wacrm`, funcional, só API oficial Meta): handoff bot↔humano
  (`src/lib/ai/auto-reply.ts:72-154`, sentinela `[[HANDOFF]]`, resumo determinístico),
  `messages.sender_type` customer/agent/bot, fila `pending_executions(run_at)` p/ follow-up,
  base de conhecimento FTS+pgvector, `ai_usage_log` p/ custo.
- Evitar: construtor visual de fluxos, broadcast, multi-tenant, telas CRUD/formulários.

## Referências externas
